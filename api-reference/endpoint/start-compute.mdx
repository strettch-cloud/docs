---
title: 'Start a compute'
openapi: '/api-reference/openapi.json POST /computes/{id}/start'
---

Starting a compute turns it on. In the dashboard this action is called [Turn On](/services/compute/turn-a-compute-off-and-on).

### Errors

| Code | Status | When |
| :--- | :---: | :--- |
| `FORBIDDEN` | 403 | The key was created by a Member. Only an Owner or an Admin can start a compute. |
| `RESOURCE_NOT_FOUND` | 404 | Your team has no compute with this ID. |
| `CONFLICT` | 409 | The compute is in a state that does not allow this. |

For every other code, see [Error codes](/api-reference/introduction#error-codes).
