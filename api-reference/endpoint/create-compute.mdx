---
title: 'Create a compute'
openapi: '/api-reference/openapi.json POST /computes'
---

The compute is billed from the moment it is created. Send an `Idempotency-Key` header with every request, so that a retry does not create a second compute. See [Idempotency](/api-reference/introduction#idempotency).

### Request values

`region`, `image` and `specification` each take a slug. Get the slugs you can use from these endpoints:

| Field | Example | Where to get the values |
| :--- | :--- | :--- |
| `region` | `KGL-1` | [List regions](/api-reference/endpoint/list-regions) |
| `image` | `UBUNTU-24.04` | [List images](/api-reference/endpoint/list-images) |
| `specification` | `S-1C-1G` | [List specifications](/api-reference/endpoint/list-specifications) |

In a specification slug, the `S` at the start stands for shared CPU.

### Errors

| Code | Status | When |
| :--- | :---: | :--- |
| `BAD_REQUEST` | 400 | A value is not valid, or the `Idempotency-Key` header is missing. |
| `INSUFFICIENT_BALANCE` | 400 | The team's credits and funds do not cover one month of the compute's price. |
| `TEAM_PAST_DUE` | 403 | The team owes money and cannot create computes until it is paid. |
| `RESOURCE_NOT_FOUND` | 404 | There is no such image, region or specification. |

For every other code, see [Error codes](/api-reference/introduction#error-codes).
