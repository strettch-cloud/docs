---
title: 'List regions'
openapi: '/api-reference/openapi.json GET /regions'
---

Use the `region` value of an entry as the `region` when you [create a compute](/api-reference/endpoint/create-compute).

### Errors

This endpoint returns only the common codes, such as `UNAUTHORIZED` and `TOO_MANY_REQUESTS`. See [Error codes](/api-reference/introduction#error-codes).
