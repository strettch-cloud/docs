---
title: 'Upsize a compute'
openapi: '/api-reference/openapi.json PATCH /computes/{id}/upsize'
---

Stop the compute before you upsize it. A compute can only go to a bigger specification, and it cannot go back. See [Upsize a compute](/services/compute/upsize-a-compute).

### Request values

`newSpecification` takes the slug of a specification, such as `S-2C-4G`. Get the slugs you can use from [List specifications](/api-reference/endpoint/list-specifications). The new specification must have at least as much CPU, RAM and storage as the current one.

### Errors

| Code | Status | When |
| :--- | :---: | :--- |
| `BAD_REQUEST` | 400 | The new specification is not bigger than the current one. |
| `COMPUTE_RUNNING` | 400 | The compute is not stopped. Stop it and try again. |
| `INSUFFICIENT_BALANCE` | 400 | The team's credits and funds do not cover one month of the new price. |
| `FORBIDDEN` | 403 | The key was created by a Member. Only an Owner or an Admin can upsize a compute. |
| `RESOURCE_NOT_FOUND` | 404 | Your team has no compute with this ID, or there is no such specification. |

For every other code, see [Error codes](/api-reference/introduction#error-codes).
