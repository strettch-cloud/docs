---
title: 'List specifications'
openapi: '/api-reference/openapi.json GET /computes/specifications'
---

Use the `specification` value of an entry when you [create](/api-reference/endpoint/create-compute) or [upsize](/api-reference/endpoint/upsize-compute) a compute.

### Errors

This endpoint returns only the common codes, such as `UNAUTHORIZED` and `TOO_MANY_REQUESTS`. See [Error codes](/api-reference/introduction#error-codes).
