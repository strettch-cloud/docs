---
title: 'List images'
openapi: '/api-reference/openapi.json GET /images'
---

Use the `image` value of an entry as the `image` when you [create a compute](/api-reference/endpoint/create-compute).

### Errors

This endpoint returns only the common codes, such as `UNAUTHORIZED` and `TOO_MANY_REQUESTS`. See [Error codes](/api-reference/introduction#error-codes).
