### Request fields

Both fields are optional. Send only the ones you want to change. A field you leave out stays as it is.

| Field | Type | Meaning |
| :--- | :--- | :--- |
| `hostName` | string | The new name of the compute. |
| `tags` | string[] | The new tags. The list you send replaces all the tags the compute has. |

### Errors

| Code | Status | When |
| :--- | :---: | :--- |
| `BAD_REQUEST` | 400 | A value is not valid. |
| `RESOURCE_NOT_FOUND` | 404 | Your team has no compute with this ID. |

For every other code, see [Error codes](/api-reference/introduction#error-codes).
