### Request Reference

Both fields are optional. Send only the ones you want to change; any field you
omit is left unchanged.

| Field | Type | Description |
| :--- | :--- | :--- |
| `hostName` | string | New host name for the compute instance. |
| `tags` | string[] | Replacement set of tags. The list you send replaces the existing tags entirely. |

---
