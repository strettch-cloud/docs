---
title: 'Delete a compute'
openapi: '/api-reference/openapi.json DELETE /computes/{id}'
---

Deleting a compute destroys it, with its disks and its IP addresses. It cannot be undone, and it works on a compute that is running. In the dashboard this action is called [Destroy](/services/compute/destroy-a-compute).

### Errors

| Code | Status | When |
| :--- | :---: | :--- |
| `RESOURCE_NOT_FOUND` | 404 | Your team has no compute with this ID. |

For every other code, see [Error codes](/api-reference/introduction#error-codes).
