The skill file describes the Strettch Cloud API to an AI coding assistant, so the assistant can write code that calls it.

## Install with skills.sh

For any agent that works with [skills.sh](https://skills.sh), such as Claude Code, Cursor, Codex, OpenCode and Goose:

```bash
npx skills add strettch-cloud/docs
```

## Download the file

<Card title="Download SKILL.md" icon="download" href="https://raw.githubusercontent.com/strettch-cloud/docs/main/skills/strettch-cloud/SKILL.md">
  Paste the contents into your AI assistant's context or system prompt.
</Card>

```bash
curl -O https://raw.githubusercontent.com/strettch-cloud/docs/main/skills/strettch-cloud/SKILL.md
```

The file works with any AI tool that supports the [Agent Skills](https://agentskills.io) format or accepts context files.
