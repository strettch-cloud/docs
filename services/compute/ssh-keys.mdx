---
title: "SSH Keys"
description: "Create an SSH key, add it to your team, and use it to log in to a compute without a password."
---

An SSH key lets you log in to a compute without typing a password. You add the public half of the key to your team, and choose it when you create a compute.

A key has two halves. The public key is the one you give to Strettch Cloud, and it is safe to share. The private key stays on your computer. Anyone who has your private key can log in to your computes, so never upload it, email it or commit it to version control.

## Create an SSH key on your computer

These commands work on Linux, macOS, and Windows in PowerShell or Windows Terminal. If you already have a key, skip to the next section.

<Steps>
  <Step title="Create the key">
    ```bash
    ssh-keygen
    ```

    Press **Enter** to accept the file location. You can set a passphrase, which protects the key if someone copies the file.
  </Step>

  <Step title="Show the public key">
    ```bash
    cat ~/.ssh/id_ed25519.pub
    ```

    If your system created an RSA key, the file is `~/.ssh/id_rsa.pub`. Copy the whole line that the command prints.
  </Step>
</Steps>

## Add an SSH key to your team

<Steps>
  <Step title="Open the SSH keys of the team">
    Go to **Team Settings** > **SSH Keys** and click **New SSH Key**. If the team has no key yet, the button reads **Add SSH Key**.
  </Step>

  <Step title="Paste the public key">
    Paste the line you copied into **Public Key**, and give the key a name in **Key Name**. A name such as `sam@macbook` tells your team whose key it is and which computer it is on.
  </Step>

  <Step title="Save the key">
    Click **Add SSH Key**.
  </Step>
</Steps>

The key is now in the team's list. Every member of the team sees all the keys, each with the name of the member who added it, and can choose any of them for a new compute. Only the member who added a key can edit or delete it.

## Use an SSH key when you create a compute

On the create page, under **Authentication Method**, choose **SSH Key** and select one or more keys. See [Create a compute](/services/compute/create-a-compute).

The keys you select are put in `~/.ssh/authorized_keys` of the `root` user, so you can [connect over SSH](/services/compute/connect-to-a-compute#connect-over-ssh) as soon as the compute is running. A compute created with an SSH key has no root password.

## Add an SSH key to a compute that already exists

Adding a key to your team does not change computes that already exist. Add the key on the compute yourself.

<Steps>
  <Step title="Log in to the compute">
    [Connect to the compute](/services/compute/connect-to-a-compute) with the web console or with the root password.
  </Step>

  <Step title="Add the public key">
    Open `~/.ssh/authorized_keys` and paste your public key on a new line.
  </Step>

  <Step title="Turn off password login (optional)">
    <Warning>
      First check that you can log in with the key. If the key does not work and password login is off, you can no longer connect over SSH.
    </Warning>

    In `/etc/ssh/sshd_config`, set `PasswordAuthentication no`, then restart SSH:

    ```bash
    sudo systemctl restart ssh
    ```
  </Step>
</Steps>
