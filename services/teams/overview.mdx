Every compute and every domain belongs to a team, and the team pays for it. Each member of a team has one role, Owner, Admin or Member, which decides what that person can do.

## How teams work

- **Resources belong to the team, not to a person.** There is no layer between a team and its resources, such as a project.
- **Each team has its own bill.** It has its own credits, funds and invoices. See [Paying your bill](/faqs/paying-your-bill).
- **Teams do not share.** A compute or a domain cannot be moved from one team to another, and one team cannot pay for another.
- **You can be in several teams.** You own some and are a member of others. The team selector, next to the logo at the top of the dashboard, switches between them.

When you sign up, we create a first team for you, named after your first name, such as "Liberi's Team".

## What each role can do

A team has one Owner. Everyone else is an Admin or a Member.

| | Owner | Admin | Member |
|---|---|---|---|
| **Computes** | | | |
| See computes, their graphs and their history | Yes | Yes | Yes |
| Create a compute, rename it, change its tags | Yes | Yes | Yes |
| Open the web console | Yes | Yes | Yes |
| Turn a compute off or on, reboot it, upsize it | Yes | Yes | No |
| Destroy a compute | Yes | Yes | No |
| **Domains** | | | |
| See domains and records | Yes | Yes | Yes |
| Add or remove domains and records | Yes | Yes | No |
| **Keys** | | | |
| Add their own SSH keys and API keys | Yes | Yes | Yes |
| **Billing** | | | |
| See the billing pages and top up | Yes | Yes | Yes |
| Edit the Entity Profile, the contact emails and the low balance alert | Yes | Yes | No |
| **Team** | | | |
| See the activity logs | Yes | Yes | Yes |
| Export the activity logs | Yes | Yes | No |
| Invite members, change roles, remove members | Yes | Yes | No |
| Rename the team | Yes | No | No |
| Transfer ownership | Yes | No | No |
| Delete the team | Yes | No | No |
| Leave the team | No | Yes | Yes |

An [API key](/api-reference/create-an-api-key) can do what the member who created it can do.

See [Managing teams](/services/teams/managing-teams) for how to invite people and change their roles.

## How many teams you can have

There is a limit on the number of teams one person can own. You see it in **Account Settings**, on the **TEAMS** tab. Each team also has [limits on its computes and public IPs](/services/compute/overview#limits-for-a-team).

## If a member breaks the rules

<Warning>
  If any member of a team uses one of its resources for a violation, such as illegal activity on a compute, we shut down all the resources of that team at once while we investigate. The team may be banned permanently.
</Warning>
