Each entry links to its page on the [Terraform Registry](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs), which has every argument, attribute and example for the provider version you use.

## Resources

A resource creates and manages something.

| Resource | What it manages |
| --- | --- |
| [`strettchcloud_compute`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/resources/compute) | A compute: create, update, upsize, reboot and destroy. |

## Data sources

A data source reads a value that exists, so your files do not depend on a slug that can change.

| Data source | What it returns |
| --- | --- |
| [`strettchcloud_compute`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/data-sources/compute) | One compute, by ID. |
| [`strettchcloud_image`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/data-sources/image) | One image, by filter. |
| [`strettchcloud_images`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/data-sources/images) | Every image. |
| [`strettchcloud_region`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/data-sources/region) | One region, by slug. |
| [`strettchcloud_regions`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/data-sources/regions) | Every region. |
| [`strettchcloud_specification`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/data-sources/specification) | One specification, by slug or by CPU and RAM. |
| [`strettchcloud_specifications`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/data-sources/specifications) | Every specification. |

## Actions

An action runs one operation. Actions need Terraform 1.14 or newer.

| Action | What it does |
| --- | --- |
| [`strettchcloud_compute_reboot`](https://registry.terraform.io/providers/strettch-cloud/strettchcloud/latest/docs/actions/compute_reboot) | Reboots a running compute, on demand or from a lifecycle event. |
