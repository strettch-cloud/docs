The provider authenticates with a Strettch Cloud API key. It sends the key as a bearer token on every request.

## Create an API key

[Create an API key](/api-reference/create-an-api-key) in the dashboard. The key acts with the same [permissions](/services/teams/overview#what-each-role-can-do) as the member who created it.

## Give the key to the provider

Set the key in the `STRETTCH_CLOUD_API_KEY` environment variable. This keeps it out of your Terraform files:

```bash
export STRETTCH_CLOUD_API_KEY="YOUR_API_KEY"
```

```hcl main.tf
provider "strettchcloud" {
  # api_key is read from STRETTCH_CLOUD_API_KEY
}
```

A key you type in a command is saved in your shell history. To avoid that, let the shell read it without showing it:

```bash
read -rs STRETTCH_CLOUD_API_KEY && export STRETTCH_CLOUD_API_KEY
```

You can also pass the key with the `api_key` argument. Do this only when the value comes from a variable or a secret store, never as text in a file you commit:

```hcl
variable "strettchcloud_api_key" {
  type      = string
  sensitive = true
}

provider "strettchcloud" {
  api_key = var.strettchcloud_api_key
}
```

<Warning>
  A saved plan (`terraform plan -out=...`) stores the values of input variables as clear text, even when a variable is marked `sensitive`. Anyone who can read the plan file can read the key. In automation, use the environment variable, and protect any plan file you keep.
</Warning>

If a key is ever exposed, revoke it in the dashboard and create a new one.

## In CI

Store the key as a secret in your CI system and pass it to the plan and apply steps as `STRETTCH_CLOUD_API_KEY`. In GitHub Actions:

```yaml
env:
  STRETTCH_CLOUD_API_KEY: ${{ secrets.STRETTCH_CLOUD_API_KEY }}
```

Verbose logging such as `TF_LOG=TRACE` can print environment variables. Do not use it in runs whose logs other people can read.

## On HCP Terraform

Set `STRETTCH_CLOUD_API_KEY` as a sensitive environment variable on the workspace. HCP Terraform then does not show the value again, in its interface or through its API.
