Give your AI coding assistant complete knowledge of the Strettch Cloud Terraform provider so it can write correct configuration in one shot.

## Install via skills.sh

The fastest way for any [skills.sh](https://skills.sh)-compatible agent (Claude Code, Cursor, Codex, OpenCode, Goose, and more):

```bash
npx skills add strettch-cloud/docs
```

This picks up every Strettch Cloud skill, including the Terraform provider.
