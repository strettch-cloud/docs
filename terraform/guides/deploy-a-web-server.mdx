sidebarTitle: "Deploy a web server"

---

You build a compute with a public IP that you log in to with your own SSH key, and Nginx on it serving a page over HTTP. At the end you destroy it. You pay for the compute and its public IP until then.

You need Terraform installed and your API key in `STRETTCH_CLOUD_API_KEY`. The [Quickstart](/terraform/quickstart) and [Authentication](/terraform/authentication) cover both. You also need an SSH key pair with the public key at `~/.ssh/id_ed25519.pub`. See [SSH Keys](/services/compute/ssh-keys) to create one.

<Steps>
  <Step title="Set up the project">
    Create a new directory with three files:

    <CodeGroup>
    ```hcl main.tf
    terraform {
      required_providers {
        strettchcloud = {
          source  = "strettch-cloud/strettchcloud"
          version = "~> 1.0"
        }
      }
    }

    provider "strettchcloud" {
      # api_key is read from STRETTCH_CLOUD_API_KEY
    }

    resource "strettchcloud_compute" "web" {
      host_name      = "web-01"
      image          = "UBUNTU-24.04"
      region         = "KGL-1"
      specification  = "S-1C-1G"
      public_keys    = [var.ssh_public_key]
      with_public_ip = true
      tags           = ["web", "demo"]
    }
    ```

    ```hcl variables.tf
    variable "ssh_public_key" {
      description = "Your SSH public key (contents of e.g. ~/.ssh/id_ed25519.pub)."
      type        = string
    }
    ```

    ```hcl outputs.tf
    output "public_ip" {
      value = strettchcloud_compute.web.ipv4
    }
    ```
    </CodeGroup>
  </Step>

  <Step title="Initialize and apply">
    Download the provider and create the compute. The command passes your public key in:

    ```bash
    terraform init
    terraform apply -var="ssh_public_key=$(cat ~/.ssh/id_ed25519.pub)"
    ```

    Read the plan and type `yes`. When the compute is running, Terraform prints its `public_ip`.
  </Step>

  <Step title="Connect over SSH">
    SSH to a compute uses [port 222](/services/compute/connect-to-a-compute#which-port-to-use). Connect as `root`:

    ```bash
    ssh root@$(terraform output -raw public_ip) -p 222
    ```
  </Step>

  <Step title="Install Nginx">
    On the compute, install Nginx:

    ```bash
    apt update && apt install -y nginx
    ```

    Replace the default page with your own:

    ```bash
    echo "<h1>Hello from Strettch Cloud</h1>" > /var/www/html/index.html
    ```

    Then leave the compute:

    ```bash
    exit
    ```
  </Step>

  <Step title="Check that it works">
    On your own computer, ask the web server for the page:

    ```bash
    curl http://$(terraform output -raw public_ip)
    ```

    You see the line you wrote:

    ```text
    <h1>Hello from Strettch Cloud</h1>
    ```
  </Step>

  <Step title="Destroy everything">
    Destroy what you created so that billing stops:

    ```bash
    terraform destroy -var="ssh_public_key=$(cat ~/.ssh/id_ed25519.pub)"
    ```
  </Step>
</Steps>

## Keep the files

The web server is now described in three files. Commit `main.tf`, `variables.tf` and `outputs.tf` to Git. Run `terraform plan` before every change to see what it will do. Apply the same files again to create an identical compute, for example for a second environment.

The files above use fixed slugs for `image`, `region` and `specification`. To look them up instead, see [Look up images, regions and specifications](/terraform/quickstart#look-up-images-regions-and-specifications).
